### 3.5 收敛后的根因（本轮定稿）

关键反证来自模块④自身：gen 图 `VibeDeadOfNight-Gen.SC2Map` **同样是亡者之夜衍生图**、同样 `PRESELECTED=false`，却稳定 tier100 PASS。两图唯一的结构性差异在构建管线：

| | gen 图（PASS） | live packed 图（RPC 死） |
|---|---|---|
| 管线 | `mpq_build_gen_map.py`（全量：内核 + 11676 gen adapter + header + dup-proto 门禁） | `mpq_inject_workspace_kernel.py`（仅内核 + 10 header 声明） |
| 战役触发器栈 | 已剥离（参见同目录 `_rebuild_no_triggers.py`） | **完整保留**（CMRE launcher + 亡者之夜战役逻辑） |
| 开局 | 立即真正 in_game | 卡在 launcher/开局前序，游戏钟不推进 |

**归因**：内核的注册标记写在 init 阶段、第一个 `Wait` 之前 → 所以标记有；PollLoop 的每轮迭代依赖 `Wait` 后的游戏时间推进 → 移植图从未真正开局，循环拿不到执行片 → 所有请求无人消费 → timeout。**这同时解释了 3.3 的 RPC 死和 3.4 的阵营未初始化——是同一个「游戏没真正开起来」的两个表征，而非两个独立问题。**

`run_live_rl.py` 那 12/12 `action_errors` 也是同一根因的下游表现：对一个没有己方单位、没有资源的伪局面发战术指令，必然全 false。
