# 执行摘要  
本报告提出基于“四维成本（矿物M、气体G、人口S、建造时间T）+多维战斗属性（HP/有效HP、DPS、射程、移动速度、护甲、护盾、技能/特殊能力、占位/碰撞、定位等）”的SC2单位平衡模型。首先收集SC2官方与社区数据，对Marine、Marauder、Stalker、Immortal、Siege Tank、Zealot六个代表单位进行特征归纳（见表1）。然后采用影子价格法将成本向量$C=(M,G,S,T)$映射到标量成本$C_{\rm scalar}$（例如初值假设$P_M=1,P_G=1.5,P_S=30,P_T=0.5$），并定义静态战斗价值$V_{\rm static}$（综合考虑有效生命、输出、射程等属性加权和）。计算各单位的**BalanceScore = $V_{\rm static}/C_{\rm scalar}$**，作为平衡基准值（基准区间建议0.95–1.05）。此外，分析单位定位与技能（如Blink、Stim、Barrier、要塞模式、AoE、伤害加成、隐身等）的数值化思路，提出“期望影响×可用性×可靠性”的估值框架。考虑单位体积/占位对专注火力、AoE效率的衰减效应，并给出调整方法。最后给出参数权重表及阈值区间、报警规则和常见平衡调整手段建议，如对过强单位加大资源/建造时间或削弱伤害/范围/技能，反之则进行相反调整。  
- **主要结果示例**：六个单位的基准平衡值（BalanceScore）在表2汇总；示例战斗模拟说明了输出对决的相对优势（见第**模拟方法**节）。

## 二、四维成本与综合成本标量  
将单位成本视为向量$C=(M,G,S,T)$，引入影子价格$P_M,P_G,P_S,P_T$将其线性映射为标量成本$C_{\rm scalar}=P_M M+P_G G+P_S S+P_T T$。若无历史均衡推导，可先假设一个初始值（如$P_M=1,P_G=1.5,P_S=30,P_T=0.5$），并在报告中说明。以此为例，上表单位的标量成本计算如下：  
- Marine：$C_{\rm scalar}=50×1+0×1.5+1×30+25×0.5=92.5$  
- Marauder：$100×1+25×1.5+2×30+30×0.5=212.5$  
- Stalker：$125+50×1.5+2×30+27×0.5=273.5$  
- Immortal：$250+100×1.5+4×30+39×0.5=539.5$  
- Siege Tank：$150+125×1.5+3×30+31×0.5=443.0$  
- Zealot：$100+0+2×30+27×0.5=173.5$  

这些$P$值可通过**线性规划**或游戏经济数据（如资源生成速率、单位使用频率、胜率等）反推。Valdivia 等研究表明，可定义生产效率指标$TA=\frac{C_{\rm scalar}}{T}$，进而根据各单位相对产出时间调整建造时间。例如，将各单位建造时间标准化，使$C/T$比一致，是一种常见做法。  

## 三、静态战斗价值模型  
我们定义每个单位的静态战斗价值$V_{\rm static}$为其关键战斗属性的加权和，形式上可写为：  
$$V_{\rm static}=w_H EHP + w_D D_{\rm ground} + w_{D_a}D_{\rm air} + w_R \cdot R + w_S \cdot V_{\text{speed}} + w_A\cdot A_{\text{value}} + \dots$$  
其中：  
- $EHP$（Effective HP）：单位实际生命与护盾及护甲加成后的有效生命值，如$EHP = HP\times(1+Armor) + Shield$（护盾再生忽略）。  
- $D_{\rm ground},D_{\rm air}$：地面/空中平均DPS，可分别计算并按典型目标分布加权。  
- $R$：攻击射程，可转化为“先手价值”（例如标准远程单位基准）。  
- $V_{\text{speed}}$：移动速度，对输出频率和追击/躲避能力的重要性。  
- $A_{\text{value}}$：单位独有技能价值，如AoE伤害、加速、减速、护盾、隐身等的综合评价，可估算为“预期影响×可用时间比例×触发概率”。  
- 还有（collision）影响伤害输出或AoE效率，可纳入$w_C$权重；**单位定位**（坦克、支援、输出）一般在模型外作为平衡参数，比如说坦克型偏重存活能力。  

各指标初步权重可设为（可根据实际需要微调）：  
- HP/EHP（含护盾、护甲）：$w_H\approx0.2$ （变动范围0.1–0.3，护甲每点约当+20%血量）。  
- 地面DPS $w_D\approx0.25$（0.15–0.35）；空中DPS $w_{D_a}\approx0.05$（0–0.1，因为多数为地面战）。  
- 射程 $w_R\approx0.1$（0.05–0.15）；速度 $w_S\approx0.05$（0.02–0.1）。  
- 护甲 $w_{armor}\approx0.1$（0.05–0.15）；护盾 $w_{shield}\approx0.05$（0–0.1）。  
- 技能/特殊 $w_A\approx0.15$（0.05–0.25），包括AoE、缓速、加速、隐身、护盾等能力。  
- 碰撞/占位 $w_C\approx0.05$（0–0.1），体积大单位受聚焦火力影响更大，等效输出下降。  

这样$V_{\rm static}$与$C_{\rm scalar}$量纲对应，得到单位的**BalanceScore**。例如，以上表数据和权重假设计算：  
- Marine：计算出$V_{\rm static}$后，BalanceScore ≈ $V_{\rm static}/92.5$。  
- Marauder：$/212.5$，等等。

## 四、技能与定位价值调整  
静态模型只能大致反映单位的单发输出与存活能力，对于**技能和单位定位**需额外量化：  
- **Blink/Charge**：增加机动性与先手概率。可视为短时速度或射程提升。例如Blink可近瞬移规避一次伤害，可估算为+$ΔV$。**建议量化**：根据激活概率和载入影响计算预期增益，如$Value_{Blink} = V_{\rm static} \times (增益概率\times 技能效率)$。  
- **Stim**：短暂增伤减血，可视为临时DPS加成约50%。实际价值依赖使用时长和生命损失。可用$p_{\rm use}\times Δ\!DPS - $生命代价形式评估。  
- **Barrier（能量护盾）**：Immortal每32秒提供100点屏障，对关键攻击提供容错。等价于增加部分有效血量。可估为+100（两秒后失效）**HP相当值**，按存在概率平摊。  
- **Siege Mode/AoE**：可对群体或远程打击，输出效率大增。建议使用**战斗模拟**：例如仿真几个Tank群 vs 海量群兵，统计AoE造成的额外击杀数。也可按平均命中单位数*伤害计算价值。  
- **Bonus dmg**：如Marauder对装甲、Hellion对生物，需乘以目标系数。可假设某比赛环境下装甲单位占比$p$，则预期DPS提升$p\times 加伤值$。  
- **脱离边界**：本模型暂不处理心理/经济策略层面，仅专注战斗效率。

**示例量化**：“期望影响×可用性×可靠性”方法：以Zealot冲锋为例，其第一次攻击若命中有额外伤害（一般打满血时概率100%），冲锋冷却8秒；若平均每次作战中使用$u$次冲锋，每次平均附加$Δ$伤害，则可估算附加DPS$\approx u×Δ/(战斗时长)$，进而乘以单位攻击效率得等效价值。

## 五、碰撞体积与占位影响  
单位体型大（碰撞半径大）会降低部队密度，减少专注火力输出；相反，小单位可更紧密包围目标。常见处理方法：  
- **关注火力系数修正**：假设一格空间能容纳$\propto1/r^2$单位（$r$为碰撞半径），则每秒总DPS∝$(单位数)\times DPS/目标准占位数$。大单位单位数少，等效输出下降。可引入修正系数$f_C=\frac{(r_{\rm baseline}/r_{\rm unit})^2}{1}$，调整其实际DPS或价值。比如以海量海兵排列为基准，当Stalker（$r\approx0.625$）与Marine（$r=0.375$）混战时，每单位Stalker所能被多名海兵同时聚焦程度低于Marine。  
- **AoE效率**：大单位占位高影响周围友军覆盖，同样影响被AoE命中的概率。可在仿真中考虑单位体积对AoE散射概率的修正。  

## 六、参数权重与阈值  
总结上述维度，可制定**可调参数表**：  

| 维度       | 建议权重 (可调范围)   | 含义与理由                           |
|:---------:|:----------------:|:--------------------------------|
| HP/EHP    | 0.15 （0.10–0.25）| 存活能力，护甲可类比额外HP；队伍的耐久总量 |
| 地面DPS   | 0.25 （0.15–0.35）| 主要输出指标，单位存续时间内输出量     |
| 空中DPS   | 0.05 （0–0.10）  | 空中目标输出，仅对部分单位 relevant      |
| 射程       | 0.10 （0.05–0.15）| 决定先手和消耗距离，大射程价值更高       |
| 移动速度   | 0.05 （0.02–0.10）| 机动性：追击和撤退能力，影响交战效率     |
| 护甲       | 0.10 （0.05–0.15）| 相当于生命增益，减伤效果               |
| 护盾       | 0.05 （0–0.10）   | Protoss 独有，平均价值约75资源|
| 技能/特殊  | 0.15 （0.05–0.25）| AoE、Buff、减速、隐身等高阶价值         |
| 碰撞占位   | 0.05 （0–0.10）   | 体积影响火力密度，小单位可聚焦更多火力  |
| **合计**   | **1.00**          |                                    |

**基准区间与报警规则**：一般BalanceScore处于[0.95,1.05]视为平衡。低于0.90应警示过弱（建议提升属性或降低成本）；高于1.10则显过强（考虑削弱）。例如，如果某单位Score>1.05，可增高其矿/气/供给/建造时长，或降低伤害/射程/技能触发概率；反之则对单位进行加强。

## 八、结论与可操作建议  
通过上述模型，我们得到各单位相对于综合成本的**基准战斗价值**。当BalanceScore超出预设范围时，应进行平衡调整。例如：  
- **过强单位**：适当提高其矿/气成本或供给，提高建造时长；或削弱火力（伤害、射程）或技能效果（冷却、持续时间）；或增大其碰撞体积/降低机动性，从而间接降低对线输出密度。  
- **过弱单位**：反向操作，如减费、降人口、缩短建造、增加输出、提升技能加成等。  

最终可得一张汇总表（表2）展示每个单位的BalanceScore基准值，并配合调整阈值告警（如Score<0.9或>1.1时提示）。参数权重表与阈值机制应可调，以适应不同版本或平衡需求。
