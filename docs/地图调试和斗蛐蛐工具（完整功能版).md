# 地图调试和斗蛐蛐工具（完整功能版）使用说明

> 本文档由截图 OCR（PaddleOCR）识别整理。顶部菜单栏、筛选控制区、底部状态栏文字识别可靠（置信度 >0.9）；中间条目列表区因字号小且密集，OCR 识别不准确，相关说明为基于界面布局的推断。部分英文状态名已根据上下文补全完整拼写。

## 一、工具概述

这是 StarCraft II 地图内的一个调试与测试工具，集成了单位创建、技能/行为/物品/武器/科技查看、单位统计、伤害统计、斗蛐蛐（单位对战测试）等功能。截图当前处于“技能”分类页，技能总数 1621 个。

## 二、界面布局

界面自上而下分为五个区域。

| 元素 | 说明 |

| 功能(2) | 功能标签页（可能含功能1 / 功能2） |
| 隐藏默认UI | 切换显示/隐藏游戏默认 UI |
| 单位统计 | 打开单位统计面板 |
| 伤害统计 | 打开伤害统计面板 |
| 清屏 | 清除屏幕上的调试信息 |
| 斗 | 斗蛐蛐（单位对战测试）入口 |
| U 9% | 右上角百分比指示（具体用途待确认） |

底部还有翻页箭头按钮。

## 三、使用流程

1. 选择分类：点击顶部标签（单位 / 技能 / 行为 / 物品 / 武器 / 科技）切换查看类型。
2. 筛选条目：使用“全部种族”“全部类别”下拉筛选，或在“搜索”框输入关键字。
3. 翻页浏览：列表分页显示，通过“第 N 页”及翻页按钮切换。
4. 创建单位：在“所属玩家”选择目标玩家，“创建数量”设置数量，选中条目后创建。
5. 查看统计：通过“单位统计”“伤害统计”按钮查看数据。
6. 斗蛐蛐测试：通过“斗”入口进入单位对战测试模式。
7. 隐藏 UI：点击“隐藏默认UI”切换游戏原生界面显示。

## 四、快捷键

## 五、OCR 识别说明

- 顶部标题栏、分类标签、筛选控制区、底部状态栏：PaddleOCR 识别置信度 >0.9，内容可靠。
- 中间条目列表区：字号小且密集，识别置信度 <0.5，具体条目内容未能准确提取，需实际使用时查看。
- 部分英文状态名为 SC2 触发器变量名，已根据上下文补全完整拼写（如 DisabledState、NotTradeShown、CenterAlignment）。
- 原始 OCR 数据（含坐标与置信度）可重新运行 PaddleOCR 复现。
